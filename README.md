# Arcane Dashboard

Website + dashboard for the Arcane bot on Yapper.

1. Add your bot pfp as `public/arcane.png` (optional, a fallback emblem shows without it).
2. Import this repo in Vercel and add the variables from `.env.example`.
3. In the Yapper developer portal set the redirect URI to `https://YOUR-SITE.vercel.app/api/callback`.
